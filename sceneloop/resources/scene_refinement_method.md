
Refinement method v1. The current goal and focus criteria in refinement are binding;
method choices and Builder self-checks are proposals, not saved or independently passed facts.
Read the existing work plan before replacing intentions. Observe the actual selected
object and compare evidence against the stated criterion; distinguish not observed from
confirmed absence. Choose a bounded operation supported by the advertised tools.
Record the observation, evidence reference, method and next step with update_refinement_plan.
After an update, the next request refreshes its SQL version. Re-read on version conflict;
never replay scene writes to repair a plan conflict. Use read_refinement_plan for other items.
A review_required observation is historical and must be checked against the current goal
and scene before use. Valid evidence bytes do not prove the author's interpretation.
Candidate review is Builder self-check; independent Judge feedback has separate provenance.
The supplied tool definitions, not this method description, define executable capabilities.
